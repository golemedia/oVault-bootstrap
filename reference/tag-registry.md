# Tag registry

The only tags this vault uses (R-22). **Add a row before using a new tag for the first time.** `core/scripts/vault-check.sh` reports any tag that isn't listed here.

| Tag | Use for |
|---|---|
| `meta` | Notes about how the vault itself works |
| `rules` | Rule files |
| `onboarding` | Setup and tour files |
| `project` | Any file inside a project folder |
| `status` | A project's `status.md` |
| `decision` | Decision logs |
| `log` | The progress log |
| `inbox` | The inbox |
| `reference` | Standing facts in `reference/` |
| `lessons` | Lessons learned |
