# Lessons learned

General lessons that carry across projects (R-20): platform quirks, methods that work, traps to avoid. Check this file before debugging a kind of problem you've seen before. What happened in a single project goes in that project's `failures.md` instead.

**Entry format:**

```
### Short lesson title
**Lesson:** the general rule, in one or two sentences.
**Applies when:** how to recognize the situation.
**Learned:** YYYY-MM-DD, in [[projects/name/INDEX]] (or wherever it came from).
```
