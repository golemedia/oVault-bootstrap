# Progress log

What happened, in order (R-06). **Newest entry at the top**, because the next session reads only the most recent one. Record decisions as one line plus a link to where the reasoning lives, never the reasoning itself (R-05).

**Entry format:**

```
## YYYY-MM-DD
- What happened, one line each.
- Decided X, see [[projects/name/decisions]].
```
